Если термин имеет несколько значений в отрасли, здесь фиксируется только принятое проектное значение. Неутверждённые конструктивные решения не следует трактовать как требования.

## 1. Общие правила терминологии

1. Использовать термины и написания из настоящего документа во всех материалах проекта.
2. Для одного объекта применять одно основное название. Синонимы допускаются только как поисковые или поясняющие варианты.
3. Не вводить новые сокращения без расшифровки при первом употреблении.
4. Различать оптические, механические и технологические базы.
5. Различать первоначальную юстировку и эксплуатационную регулировку. Для текущей архитектуры предусмотрена только однократная юстировка при изготовлении и сборке.
6. Если значение или конструкция ещё не определены, явно указывать статус «не определено» или «требует разработки», а не подменять его предположением.

## 2. Оптическая система

| Термин | Определение и применение в проекте |
|---|---|
| **Оптическая система** | Совокупность оптических элементов и промежутков между ними, формирующая изображение в соответствии с расчётной схемой. |
| **Оптическая схема** | Расчётное представление состава, последовательности и параметров оптических поверхностей и элементов. |
| **Оптическая ось** | Опорная ось оптической системы, относительно которой задаются положения и углы элементов. Способ её переноса в механические базы подлежит разработке. |
| **Входная линза** | Одна из двух крупных линз передней оптической группы, через которые свет поступает в систему. |
| **Центральное отверстие** | Отверстие в каждой из двух больших входных линз. Используется в проектируемой технологии совместного центрирования и для размещения корректирующего блока. |
| **Зеркало Манжен** | Зеркальный оптический элемент заднего узла. В проектной документации использовать именно это написание. |
| **Блок корректора** | См. пункт 2.2 настоящего глоссария. |
| **Возвратный световой пучок** | Световой пучок, который после отражения от зеркала Манжен распространяется обратно через центральную область входной оптической группы к приёмному узлу. |
| **Воздушный промежуток** | Расстояние между указанными оптическими поверхностями, заполненное воздухом. В оптической таблице один физический промежуток может быть представлен несколькими поверхностями на прямом и обратном ходе лучей. |
| **Плоскость изображения** | Расчётная плоскость, в которой оптическая система формирует изображение. Физическая плоскость фотоприёмной матрицы должна совпадать с ней в пределах установленных допусков. |
| **Фотоприёмная матрица** | Чувствительный элемент приёмного узла, регистрирующий сформированное оптической системой изображение. |
| **Поле изображения** | Область изображения, формируемая системой в плоскости изображения. |
| **Входной зрачок** | Изображение апертурной диафрагмы со стороны пространства предметов; определяет эффективную входную апертуру системы. |
| **Угловое поле** | Угловая область пространства предметов, отображаемая оптической системой. |
| **Энергия в кружке (Encircled Energy)** | Доля энергии изображения, попадающая внутрь окружности заданного диаметра в плоскости изображения. |

### 2.2. Блок корректора

**Три корректирующие линзы, установленные в собственной оправе. Блок располагается в центральных отверстиях входных линз переднего апертурного узла.**

**Конструкция должна обеспечивать установку, юстировку и последующую фиксацию блока корректора относительно зеркала Манжена.**

**Взаимное расположение блока корректора и входных линз должно обеспечивать требуемую концентричность оптических элементов.**

## 3. Механика и базирование

| Термин | Определение и применение в проекте |
|---|---|
| **Оптико-механическая конструкция** | Совокупность оправ, несущих элементов, креплений и интерфейсов, обеспечивающих заданное положение и сохранность оптических элементов. |
| **Передний оптический блок** | Узел с двумя крупными входными линзами и общей передней титановой оправой. |
| **Задний узел зеркала Манжен** | Механическая сборка, содержащая зеркало Манжен, его оправу/крепление и средства первоначального позиционирования. |
| **Корректирующий узел** | Механическая сборка, удерживающая три корректирующие линзы в центральной области передней оптической группы. |
| **Несущий каркас** | Силовая структура, связывающая переднюю и заднюю оправы и обеспечивающая требуемую жёсткость и стабильность взаимного положения. |
| **Оправа** | Деталь или сборка, предназначенная для установки, базирования и удержания оптического элемента либо группы. |
| **Ламель** | Продольная пластинчатая деталь несущего каркаса, соединяющая переднюю и заднюю оправы. |
| **Технологическая оправка** | Временная сборочная оснастка, проходящая через центральные отверстия больших линз и задающая общую ось при их центрировании. Не является автоматически частью готового изделия. |
| **Механическая база** | Поверхность, ось или система геометрических элементов, относительно которых задают положение детали или узла при изготовлении, измерении либо сборке. |
| **Оптическая база** | Опорная ось, поверхность или система параметров, определяемая оптической схемой и используемая для задания требуемого положения оптических элементов. |
| **Соосность** | Совпадение заданных осей в пределах установленного допуска. |
| **Центрирование** | Совмещение заданного центра или оси элемента с принятой базовой осью в пределах допуска. |
| **Децентрировка** | Поперечное смещение оптического элемента относительно заданной оси или расчётного положения. |
| **Наклон** | Угловое отклонение элемента от заданной ориентации. |
| **Кожух** | Наружный защитный элемент. В текущей концепции его основная функция — защита от паразитной засветки; несущая функция не назначена. |
| **Опорный пилон** | Наклонный несущий элемент, связывающий выносной приёмный узел с передней оправой. В концепции предусмотрены три пилона. |

## 4. Позиционирование, юстировка и фиксация

| Термин | Определение и применение в проекте |
|---|---|
| **Позиционирование** | Изменение координат или ориентации элемента для достижения требуемого положения. Само по себе не означает, что положение оптически проверено. |
| **Юстировка** | Измеряемое выставление оптического элемента или узла относительно оптических баз и других элементов по заданным критериям. |
| **Первоначальная юстировка** | Единственная предусмотренная проектом процедура юстировки, выполняемая при изготовлении и сборке объектива. |
| **Степень свободы** | Независимая координата перемещения или поворота тела. Для первоначальной юстировки зеркала Манжен предусмотрены X, Y, Z, Rx и Ry; Rz не требуется. |
| **Фиксация** | Закрепление достигнутого положения элемента после юстировки с обеспечением требуемой жёсткости и стабильности. |
| **Регулировка** | Изменение параметра или положения после первоначальной настройки. Штатная эксплуатационная регулировка оптических узлов текущей архитектурой не предусматривается. |
| **Юстировочная оснастка** | Временные приспособления и инструменты, используемые для первоначального выставления оптических элементов. |
| **Контроль после фиксации** | Проверка того, что закрепление не вызвало недопустимого смещения или наклона и достигнутое положение сохранено. |

### 4.1. Координаты юстировки зеркала Манжен

| Обозначение | Значение |
|---|---|
| X, Y | Поперечные перемещения относительно оптической оси |
| Z | Перемещение вдоль оптической оси |
| Rx, Ry | Наклоны вокруг двух поперечных осей |
| Rz | Поворот вокруг оптической оси; для первоначальной юстировки зеркала не требуется |

**Важно:** пять степеней свободы требуются только на этапе первоначальной юстировки. После неё зеркало фиксируется по всем координатам. В эксплуатации регулировка не требуется и не предусмотрена. Наличие постоянного пятикоординатного механизма в готовом изделии не утверждено.

## 7. Правила пополнения глоссария

- Новый термин добавляется, если он повторяется в документах, влияет на трактовку требований или может иметь неоднозначное значение.
- Перед введением нового термина проверяется, нет ли уже существующего эквивалента.
- Изменение определения сопровождается проверкой связанных документов.
- Если термин отражает принятое инженерное решение, ссылка на соответствующую запись в журнале решений добавляется в определение или примечание.
- Глоссарий не должен превращаться в каталог всех общеупотребительных технических слов: включаются только термины, важные для согласованности проекта.
