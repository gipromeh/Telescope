# Папка публикации протоколов в YouGile

Помещайте сюда только те Markdown-протоколы, которые нужно передать в раздел «Совещания» Базы знаний YouGile.

- Имя файла — уникальное, например `2026-11-06_meeting.md`.
- После попадания файла в `main` локальный агент на компьютере владельца обнаружит его и создаст страницу в YouGile.
- Текст файла публикуется без преобразования Markdown-разметки и без изменения инженерного статуса предложений.
- Если протокол уже опубликован, не редактируйте этот файл для повторной публикации: добавьте отдельный файл с новым уникальным именем.
- Не помещайте сюда секреты, пароли, токены или материалы, которые не должны находиться в публичном репозитории.

Автоматическая публикация работает только после локальной установки агента, его входа в YouGile и запуска задачи Windows Task Scheduler. Подробности: [локальный издатель Базы знаний YouGile](../../DOCUMENTATION/YOUGILE_KB_UI_PUBLISHER.md).
