# История изменений

## 2026-11-03 — 0.9.0

- Инструкция ИИ-проектировщика обновлена до редакции 1.2.0.
- Добавлена модель инженерных экспертиз: оптический расчёт, оптико-механическое конструирование, прецизионная механика, SolidWorks/CAD, прочность, материаловедение, технологии машиностроения и оптического производства, юстировочная оснастка, метрология, покрытия, испытания, программные расчёты и независимая верификация.
- Закреплены правила выбора профильных экспертов, междисциплинарного взаимодействия, доказательной классификации данных и запрета на неподтверждённые утверждения и нерелевантные отклонения.


## 2026-11-03 — 0.8.0

- Инструкция ИИ-проектировщика обновлена до редакции 1.1.0.
- Установлена иерархия инструкций: актуальный INSTRUCTION.md в GitHub является главным изменяемым источником инженерных правил.
- Добавлен обязательный протокол сверки с веткой main перед началом новых задач и существенными действиями, включая поведение при недоступности GitHub и разрешение конфликтов источников.


## 2026-11-03 — 0.7.0

- Расширен регламент редакций: введена классификация ADD, MODIFY, DELETE, MOVE, MERGE и SPLIT.
- Установлено обязательное определение судьбы требований, исчезнувших из новой редакции.
- Закреплено сравнение только соседних редакций N−1 → N и правила постоянных ID требований.
- Добавлен процесс обработки итогов совещаний и ручной передачи полных документов во внешнюю базу знаний.
- Регламент сделан обязательным для ИИ-проектировщика.


## 2026-11-03 — 0.6.0

- Введён обязательный регламент управления редакциями текстовых документов.
- Установлены правила независимой нумерации редакций документов, выделения изменений жирным шрифтом, фиксации удалений и хранения неизменяемых архивных снимков.
- Для проект-задания [ТЗ-ОМО-001](Development/CONCEPT/PROJECT_ASSIGNMENT_TECHNICAL_DESIGN.md) зафиксирована редакция 0.5.0 от 03.11.2026; [полный архивный снимок редакции](Development/CONCEPT/REVISIONS/ТЗ-ОМО-001_v0.5.0_2026-11-03.md) опубликован отдельно.
- Добавлена ссылка на регламент в корневую навигацию.

## 2026-11-03 — 0.5.0

- Уточнён пункт 3.6 проект-задания: определены требования к совместной разработке стенда для юстировки и контроля объектива.
- Учтено центральное экранирование входного зрачка конструкцией камеры на пилонах типа «паук».
- Зафиксирована необходимость контроля основных технических и оптических характеристик при отсутствии штатной камеры.
