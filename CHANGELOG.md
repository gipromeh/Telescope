# История изменений

## 2026-11-02 — 0.1.0

- Создан репозиторий TELESCOPE.
- Добавлена базовая структура инженерной документации.
- Добавлена инструкция ИИ-проектировщика.
- Добавлен начальный паспорт без вымышленных технических характеристик.

## 2026-11-02 — 0.2.0

- Зафиксировано отсутствие АСУ в составе проекта: каталог ASU не требуется.
- Добавлен Development как основной раздел конструкторской разработки.
- Определены области компоновки, схемных решений, механики, CAD, чертежей и интерфейсов.
- Добавлен регламент сквозной инженерной трассируемости и управления ревизиями.
- В инструкцию ИИ-проектировщика включены правила трассируемости и конструкторского выпуска.
- Расширен план работ по конструированию телескопа.

## 2026-11-02 — 0.3.0

- Добавлен предварительный документ ТЗ-ОМО-001 по оптико-механической конструкции объектива.
- Зафиксирован принцип однократной юстировки с жёсткой фиксацией оптических элементов для штатной эксплуатации.
- Уточнены пять степеней свободы зеркала Манжен: только для первоначальной юстировки.
- Унифицировано написание названия зеркала: «зеркало Манжен».
